ВНИМАНИЕ: Это синтетическая тестовая инструкция для прототипа хакатона (не является регламентом Авито).

## Уровни доступа

- Стажёр имеет право запрашивать права `read` и `write` только к учебным репозиториям и пространству базы знаний СВОЕЙ команды.
- К базам знаний смежных команд (например, `space_goods_search_wiki` для стажёра из `team_auto_backend`) разрешён запрос ТОЛЬКО на уровне `read` (чтение). Запрос уровня `write` к чужому пространству будет отклонён системой контроля прав (RBAC).

## Правила доступа

- Категорически ЗАПРЕЩЁН доступ стажёров к промышленным (Production) базам данных и финансовым контурам (например, `db_fintech_prod_cluster`). Любая попытка запросить такой доступ блокируется на уровне сервера.

## Действия при блокировке или нехватке прав

Если для решения рабочей задачи стажёру требуется выгрузка данных из промышленного контура, доступ не запрашивается — необходимо обратиться напрямую к своему наставнику (buddy) для получения обезличенного дампа данных.
