# LLM-слой

Каталог для артефактов разработки AI-сценариев по подходу SDD.

| Каталог | Назначение |
|---|---|
| `prompts/` | системные и сценарные промпты агента |
| `skills/` | переиспользуемые скиллы (проверка политики, сбор полей заявки) |
| `mcp/` | конфигурация MCP-серверов для доступа агента к инструментам |

Каталоги появятся после согласования [`specs/access-request.md`](../specs/access-request.md):
сначала фиксируем поведение и инструменты, затем реализуем промпты и MCP.
